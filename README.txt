
Kyu Store v3.2 - Final (user-filled token)

Files included:
- index.js
- package.json
- config.json (contains the token and admin id you provided)
- data/products.json
- data/users.json
- data/orders.json
- utils/helper.js

How to run:
1. Upload folder to your Pterodactyl Node.js server.
2. In the folder, run:
   npm install
   node index.js
3. Bot will start and respond to /start.
Note: keep your token private. If you want it removed from config.json, edit it before running.
